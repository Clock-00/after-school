# 백암초 강사 경력관리 Apps Script 시험 배포

새 Apps Script 프로젝트에서 가상 데이터와 이메일 초대를 시험합니다. 메일은 배포 계정 권한으로 Google MailApp이 보내므로 별도 SMTP 서비스는 필요하지 않습니다.

## 배포

1. 저장소에서 `node _apps-script/prepare.mjs`를 실행하면 `_apps-script/build/`에 업로드할 파일이 생성됩니다.
2. 배포를 담당할 계정으로 새 독립형 Apps Script 프로젝트를 만듭니다. 생성된 `Code.js`, `DemoData.js`를 스크립트 파일로, `Index.html`, `Styles.html`을 HTML 파일로 넣고 `appsscript.json`을 반영합니다. 기존에 쓰는 출결·출근 프로젝트와 분리합니다.
3. 프로젝트 설정의 **스크립트 속성**에 `ADMIN_EMAIL`(관리자가 메일을 받을 주소)과 `AUTH_SECRET`(64자리 랜덤 16진 문자열)을 저장합니다. 비밀값은 로컬 터미널에서 `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`로 생성할 수 있습니다. 저장소나 채팅에 넣지 않습니다.
4. **배포 → 새 배포 → 웹 앱**에서 실행 계정은 배포자 본인, 액세스 권한은 **모든 사용자**로 선택하고 MailApp 권한을 승인합니다. 익명 방문자는 이메일 입력 화면까지만 볼 수 있고, 서버가 유효한 인증번호와 세션을 확인한 뒤 가상 경력을 반환합니다.
5. 새 `/exec` 링크에서 관리자 이메일로 인증번호를 요청합니다. 받은 메일의 번호로 로그인하고, 시험 담당자 이메일을 초대합니다. 다른 브라우저에서 담당자의 조회, 관리자 기능 차단, 접근 해제를 확인합니다. 미등록 주소로는 인증번호가 발송되지 않습니다.

## 시험 범위

- 인증번호 유효 시간은 10분, 로그인은 세션당 최대 8시간입니다. 페이지를 새로 열면 다시 로그인해야 합니다. 같은 계정의 새 로그인은 이전 세션을 대체합니다.
- 가상 데이터 조회와 초대·해제만 제공합니다. 실제 강사 자료는 연결하지 않습니다. 운영 전 학교 승인, 비공개 원본 저장소, 운영 권한과 감사 정책을 확정합니다.
- 도구 검증은 `node --test _apps-script/auth.test.mjs`로 실행합니다. 이 테스트는 Google 서비스를 모의 실행하며 배포 계정의 메일 권한과 실제 수신을 검증하지 않습니다.
