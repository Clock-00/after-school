        현재 구현된 기능

        GitHub Pages에서 동작하는 가상 강사 목록과 강사별 전체 경력 조회를 제공합니다.

        아직 구현되지 않은 기능

        로그인, 실제 개인정보 저장, Google Sheets 연계, 승인, PDF 발급은 구현되어 있지 않습니다.

        중요한 보안 안내

        GitHub Pages에 게시된 화면과 소스코드는 외부에 공개될 수 있습니다. 개인정보, API 키, 비밀번호, 계약서, 출근부, 증명서 파일을 저장소에 올리지 마세요.
