# 백암초 방과후 강사대장 Apps Script

관리자, 업무 담당자, 승인 담당자 중 하나를 선택하고 해당 역할의 공용 비밀번호로 로그인합니다. 기록에는 처리한 역할이 남습니다.

1. 스프레드시트의 **확장 프로그램 → Apps Script**에서 `Code.gs`, `Index.html`, `Password.html`, `appsscript.json`을 적용합니다.
2. 스프레드시트를 새로고침하고 **강사대장 설정 → 대장 초기화**를 실행합니다.
3. 스프레드시트 소유자가 **강사대장 설정**에서 역할별 비밀번호를 각각 설정합니다. 입력값을 다시 표시하지 않습니다. 비밀번호를 바꾸면 같은 역할의 이전 비밀번호와 세션이 무효화됩니다.
4. 초기 배포의 접근 범위는 **나만**입니다. 담당자와 공유하려면 학교 정책에 맞는 범위로 배포하고 역할별 비밀번호를 해당 담당자에게 전달합니다.
5. 가상 강사와 계약을 등록하고 다른 역할에서 발급을 승인합니다. 승인 문서는 인쇄하거나 PDF로 저장할 수 있습니다. 학교 공식 서식은 별도로 적용해야 합니다.
