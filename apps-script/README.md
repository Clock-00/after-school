# 백암초 방과후 강사대장 Apps Script

담당자는 역할을 선택하고 대장 소유자가 발급한 개인 접속 코드로 로그인합니다. 이메일은 관리자 계정 등록과 처리 기록에 사용합니다. 메일 발송이나 별도 호스팅은 필요하지 않습니다.

1. 대장용 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다. `Code.gs`와 HTML 파일 `Index`에 각 파일 내용을 붙여 넣습니다. 프로젝트 설정에서 매니페스트 표시를 켜고 `appsscript.json`도 적용합니다.
2. 스프레드시트를 새로고침합니다. **강사대장 설정 → 대장 초기화**를 실행해 소유자 계정으로 승인합니다. **담당자 접속 코드 발급**에 소유자 이메일을 입력해 관리자 코드를 발급합니다.
3. **배포 → 새 배포 → 웹 앱**에서 **나로 실행**, 액세스 범위 **나만**으로 배포해 가상 기록으로 확인합니다.
4. 담당자가 이용할 배포 주소의 액세스 범위는 학교 정책에 맞추어 설정합니다. 다른 담당자가 URL에 접근할 수 있는 경우에도 대장 내용은 유효한 개인 코드와 등록 역할을 검증한 후에 제공됩니다. 스프레드시트 및 스크립트 편집 권한은 대장 소유자가 관리합니다.
5. 관리자 화면에서 담당자의 이메일과 역할을 등록한 뒤, 스프레드시트 메뉴에서 해당 계정의 코드를 발급합니다. 코드는 화면을 닫으면 다시 볼 수 없고 재발급 시 이전 코드와 세션이 무효화됩니다. 역할을 변경한 계정은 새 코드가 필요합니다.

업무 담당자가 강사 및 계약을 입력하고 발급을 요청하면 승인 담당자가 검토합니다. 승인된 활동확인서와 경력증명서는 브라우저 인쇄 창에서 PDF로 저장할 수 있습니다. 현재 양식은 확인용입니다.
