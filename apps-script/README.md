# 백암초 방과후 강사대장 Apps Script 버전

학교 Google Workspace 계정으로 접속합니다. 관리자와 같은 도메인에 있는 담당자를 관리자 화면에서 등록합니다. Google 계정 확인에 실패하거나 등록이 해제된 사용자는 대장을 열 수 없습니다.

## 처음 배포하기

1. 학교에서 승인한 Google Workspace 계정으로 빈 Google 스프레드시트를 만든 뒤 **확장 프로그램 → Apps Script**를 엽니다. 대응하는 파일에 `Code.gs`와 `Index.html` 내용을 붙여 넣습니다. HTML 파일 이름은 편집기에서 `Index`로 지정합니다.
2. 프로젝트 설정에서 **편집기에 appsscript.json 매니페스트 파일 표시**를 켜고, 매니페스트 내용을 붙여 넣습니다. 스프레드시트를 만든 계정으로 편집기에서 `setupRegister_`를 한 번 실행하고 요청된 권한을 승인합니다. 이때 해당 계정이 최초 관리자로 등록됩니다.
3. **배포 → 새 배포 → 웹 앱**에서 실행 계정을 **나**, 액세스 권한을 **학교 조직 사용자**로 설정합니다. 배포 후 받은 `/exec` 주소를 등록된 담당자에게 전달합니다. 조직 사용자 옵션이 없거나 사용자의 이메일을 확인할 수 없다는 메시지가 나오면 학교 Workspace 관리자에게 배포 정책을 확인합니다.
4. 관리자 계정으로 열어 업무 담당자와 승인 담당자를 등록합니다. 서로 다른 학교 계정으로 가상 강사 및 계약 등록, 공동 조회, 발급 요청 및 승인 흐름을 확인합니다. 원본 스프레드시트 편집 권한을 받은 사람은 웹앱을 거치지 않고 자료를 열 수 있으므로 원본은 관리 계정으로 보관합니다.

## 사용 방법

- 관리자와 업무 담당자는 강사명, 학교, 학년도, 프로그램으로 조회하고 계약과 실제 활동을 입력합니다.
- 활동이 확인된 계약을 선택해 활동확인서 또는 경력증명서를 요청합니다. 요청 시점의 내용을 발급대장에 보관합니다.
- 관리자 또는 승인 담당자가 다른 사람이 요청한 건을 승인하거나 반려합니다. 승인된 건의 **인쇄 / PDF 저장**을 누르면 브라우저 인쇄 창에서 PDF로 저장할 수 있습니다.
- 출력은 학교 공식 서식 적용 전의 확인용 양식입니다. 직인과 공식 결재는 기존 학교 절차에 따릅니다.
- 운영 전 별도 담당자 계정으로 권한을 확인하고, 학교에서 승인한 저장 및 보존 기준에 따라 실제 기록을 입력합니다.
